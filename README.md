# Anil Kumar — Video Editor Portfolio

A responsive portfolio website for Anil Kumar, an independent video editor. It is built with plain HTML, CSS, and JavaScript and has no build step.

## Pages

- `index.html` — Home page with featured work, services, FAQs, and contact links.
- `reels.html` — Short-form work and pricing.
- `long-form.html` — Long-form work and pricing.

## Run locally

Open `index.html` in a browser, or serve this folder with a local static web server.

## Update the work gallery

Edit the `reels` and `longForm` arrays near the top of `script.js`. Each project can include a title, description, YouTube video URL, optional image, and a `featured` flag. The current videos are hosted on YouTube; this folder does not include local video assets.

## Customize

- Update page text and links in the HTML files.
- Update FAQ content and project entries in `script.js`.
- Update colors, typography, spacing, and responsive styles in `styles.css`.

Google Fonts and the software logos load from their external providers. The main site and layout work without those assets, using fallback fonts where available.
